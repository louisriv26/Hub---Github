Aide de la collection

À quoi sert Collection Luisa ?

Collection Luisa rassemble en un seul endroit l’accès à quatre applications indépendantes consacrées aux écrits de Luisa Piccarreta. Elle sert de porte d’entrée : les textes et vos données personnelles restent dans chaque application.

Dois-je installer les quatre applications ?

Non. Vous pouvez utiliser Collection Luisa pour ouvrir les quatre applications sans les ajouter séparément à votre écran d’accueil. Si vous utilisez régulièrement une application, vous pouvez aussi l’ajouter directement à votre écran d’accueil.

Comment conserver mes notes et surlignages ?

Chaque application conserve ses propres notes, surlignages, favoris et progression. Selon l’appareil, le navigateur et la manière dont vous ouvrez une application, une version utilisée dans le navigateur et une version ajoutée séparément à l’écran d’accueil peuvent utiliser des espaces de stockage distincts. Pour éviter toute confusion, utilisez de préférence la même manière d’ouvrir une application. Lorsqu’une sauvegarde ou un export est proposé, utilisez-le pour vos données importantes.

Mes données sont-elles partagées entre les applications ?

Non. Collection Luisa ne lit, ne rassemble ni ne synchronise vos notes, surlignages, favoris ou progression. Chaque application conserve ses propres données.

Les réglages de Collection Luisa modifient-ils les quatre applications ?

Non. Le thème et la taille du texte choisis dans Collection Luisa s’appliquent uniquement à Collection Luisa. Chaque application conserve ses propres réglages.

Que signifie « En préparation » ?

Cela signifie qu’une application n’est pas encore proposée depuis Collection Luisa. Cela ne signifie pas qu’elle manque sur votre appareil.

Que se passe-t-il lorsque j’ouvre une œuvre ?

Collection Luisa ouvre le site de l’application choisie. Selon votre appareil et votre navigateur, l’ouverture peut se faire dans le navigateur ou dans l’application web si vous l’avez déjà ajoutée à votre écran d’accueil.

Hors connexion

Après un premier chargement, Collection Luisa peut s’ouvrir hors connexion. Pour une application individuelle, l’utilisation hors connexion dépend de ce que cette application a déjà rendu disponible sur votre appareil.

Installation

L’installation de Collection Luisa est facultative. Vous pouvez l’ajouter à votre écran d’accueil ou l’installer lorsque votre navigateur vous propose cette option. Les quatre applications restent également accessibles directement par leur propre adresse.

À noter : sur certains appareils, une application ajoutée ultérieurement à l’écran d’accueil peut utiliser un espace de données distinct de celui du navigateur. Vérifiez donc que vos données existantes sont présentes avant d’y poursuivre vos annotations.
